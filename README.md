# Цена Биткоина

Простая программа на Python, которая получает текущую цену Биткоина в долларах США через сайт CoinGecko.

## Как запустить

1. Скачай код:
   git clone https://github.com/alwaysinlimbo/bot_learning.git

2. Перейди в папку с программой:
   cd bot_learning

3. Установи нужную библиотеку:
   pip install requests

4. Запусти программу:
   python3 main.py

## Как это устроено

- config.py — хранит настройки: адрес сайта, ключ и параметры.
- api.py — содержит функцию, которая ходит на сайт и получает цену.
- main.py — запускает эту функцию и печатает результат на экран.

## Что получится

При запуске программы ты увидишь в терминале что-то вроде:
Курс Биткоина: 56789.0 USD
